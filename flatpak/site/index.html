Mirdispo

Share your Plasma desktop with Miracast and Chromecast displays.

Install

Works on any Linux distribution with Flatpak. Mirdispo appears in your application menu and updates itself with the rest of your apps.

Install Mirdispo

The button opens Discover, or your distribution's software centre, to install. If nothing happens, run this in a terminal:

flatpak install --user https://hencyber.github.io/mirdispo/mirdispo.flatpakref

Prefer a Debian package? The .deb for Debian, Ubuntu and derivatives is on the latest release.

Built on GNOME Network Displays
